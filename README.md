# مترجم الكتب بوكلاء الذكاء الاصطناعي

موقع يرفع الكتاب بأي صيغة، يحدد مساره تلقائياً، ويترجمه إلى العربية عبر فريق من الوكلاء، ثم يحفظه في مكتبة موحدة للقراءة داخل الموقع وكملف PDF بقالب واحد.

## كيف يعمل

```
رفع الملف (اسم الكتاب إلزامي)
   ↓
① الراوتر: يحدد مسارين
   • مسار الصيغة (كيف نستخرج):  PDF نصي · PDF مصوّر · PDF مختلط (قرار لكل صفحة) · صور/ZIP · EPUB · Word · نص/Markdown
   • مسار المحتوى (كيف نترجم):   أدبي · علمي · تقني · أطفال · ديني · شعر · قانوني · تطوير ذات · عام
   ↓
② الاستخراج → صيغة موحدة (فصول وفقرات وعناوين)، مع حذف رؤوس الصفحات وأرقامها ودمج الفقرات المقطوعة
   • الصفحات المصوّرة: OCR بموديل رؤية + تحقق (ثقة الموديل + فحص جودة النص + مقارنة مع Tesseract)
   ↓
③ وكيل المصطلحات: قاموس أسماء ومصطلحات + دليل أسلوب + ملخص الكتاب
   ↓
④ لكل مقطع: المترجم ← المدقق (درجة + أخطاء) ← يرجع للمترجم إذا الدرجة أقل من 8 (مرتين كحد أقصى) ← المحرر
   ↓
⑤ مدقق الاتساق على مستوى الفصل
   ↓
⑥ إخراج PDF بالقالب الموحد (كود، وليس AI) باسم الكتاب
```

- الفصول تُترجم بالتوازي، وكل مقطع يُحفظ فور انتهائه، فلو توقف الخادم يكمل من حيث وقف.
- الفقرات منخفضة الثقة (OCR ضعيف، خط يد، أو لم تنجح في التدقيق) تُعلَّم وتظهر حالة الكتاب «يحتاج مراجعة».
- لكل وكيل موديل مستقل قابل للتغيير، والمدقق افتراضياً موديل مختلف عن المترجم.

## المكتبة والقارئ

- شبكة أغلفة موحدة التصميم (تُولَّد تلقائياً أو يُرفع غلاف)، «أكمل القراءة»، بحث، تصنيفات، ترتيب، تعديل الاسم، حذف، إعادة المحاولة.
- القارئ: حجم الخط، 5 خطوط عربية، 4 مظاهر (فاتح، سيبيا، داكن، أسود)، تباعد الأسطر، عرض العمود، المحاذاة.
- النص الأصلي: عند النقر على الفقرة، أو جنباً إلى جنب.
- علامات مرجعية مربوطة بالفقرة (لا تضيع مع تكبير الخط)، والرجوع تلقائياً لآخر موضع.
- إعدادات عامة أو خاصة بكل كتاب، وإمكانية القراءة أثناء الترجمة.

## التشغيل محلياً

```bash
pip install -r requirements.txt
# بدون مفتاح: وضع اختبار يمر على كل المراحل بترجمة تجريبية
uvicorn app.main:app --reload
# التشغيل الفعلي
ANTHROPIC_API_KEY=sk-ant-... uvicorn app.main:app
```

لـ PDF تحتاج مكتبات Pango على الجهاز (موجودة في Dockerfile). على ماك: `brew install pango tesseract tesseract-lang`.

## النشر على Railway

1. أنشئ مشروعاً من هذا الريبو (يُبنى من `Dockerfile` تلقائياً).
2. أضف **Volume** واربطه على المسار `/data` (هنا تُحفظ الملفات والـ PDF).
3. أضف قاعدة **PostgreSQL**، ثم في متغيرات خدمة الموقع أضف `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (الربط ليس تلقائياً). بدونها يستخدم SQLite داخل الـ Volume.
4. المتغيرات:

| المتغير | الوصف |
|---|---|
| `ANTHROPIC_API_KEY` | مطلوب للترجمة الفعلية |
| `APP_PASSWORD` | كلمة مرور للموقع كاملاً (موصى بها، لأن الرابط عام وكل كتاب له تكلفة) |
| `MODEL_TRANSLATOR` / `MODEL_REVIEWER` / `MODEL_EDITOR` / `MODEL_OCR` / `MODEL_GLOSSARY` / `MODEL_CONSISTENCY` / `MODEL_ROUTER` | لتغيير موديل أي وكيل |
| `REVIEW_PASS_SCORE` | حد نجاح التدقيق (افتراضي 8) |
| `MAX_RETRANSLATIONS` | عدد مرات الإرجاع للمترجم (افتراضي 2) |
| `CHAPTER_WORKERS` | عدد الفصول المتوازية (افتراضي 3) |
| `SEGMENT_WORDS` | حجم المقطع بالكلمات (افتراضي 900) |

## هيكل الكود

```
app/
  main.py            الواجهات البرمجية والصفحات
  worker.py          طابور الكتب في الخلفية
  llm.py             الاتصال بـ Claude (مع تخزين السياق المشترك ووضع الاختبار)
  pipeline/
    router.py        تحديد مسار الصيغة ونوع المحتوى
    extract.py       مسارات الاستخراج
    ocr.py           OCR والتحقق من صلاحية النص
    quality.py       فحص جودة النص المستخرج
    profiles.py      إعدادات الترجمة لكل نوع محتوى
    agents.py        المصطلحات، المترجم، المدقق، المحرر، الاتساق
    run.py           تنسيق المراحل
  export/            قالب PDF الموحد
  static/            المكتبة والقارئ
  fonts/             خطوط عربية (Noto Naskh Arabic, Amiri — رخصة SIL OFL)
```

## المرحلة القادمة

التظليل والملاحظات، البحث داخل الكتاب، واجهة مراجعة الفقرات المعلَّمة، زر «بلّغ عن خطأ ترجمة»، إخراج EPUB، القراءة الصوتية، والعمل بدون إنترنت.

## حقوق النشر

الموقع لترجمة الكتب التي تملك حق ترجمتها أو كتب الملكية العامة أو للاستخدام الشخصي. نشر ترجمة كتاب محمي يحتاج إذن صاحب الحقوق.
